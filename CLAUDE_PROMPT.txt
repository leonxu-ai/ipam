# Claude Code 实施提示词

我需要你帮我实现一个企业级IPAM（IP地址管理）系统，用于中创新航工厂的网络IP管理。

## 项目背景

我在 /opt/ipim/calb-ipim/ 目录下有12个完整的前端HTML设计原型（包含登录页、仪表板、IP管理列表、子网管理、审计日志等页面），每个页面都有完整的HTML代码和设计截图。

现在需要基于这些设计原型，实现一个完整的生产级系统。

## 技术要求

### 后端
- Django 5.0.1 + PostgreSQL 15
- django-q2（异步SNMP扫描任务队列）
- pysnmp-lextudio（网络设备SNMP扫描）
- cryptography（SNMP凭证加密）

### 前端
- Django Templates（将HTML原型转换为模板）
- Tailwind CSS 3.4+（离线部署，编译为静态CSS）
- Material Symbols Outlined（离线字体）
- Inter字体（离线部署）
- Alpine.js 3.14+（轻量级交互）
- 暗黑主题为主

### 部署
- Docker + Docker Compose
- **完全离线部署**（无互联网访问）
- 局域网访问地址：http://10.21.111.129
- 所有CDN资源必须本地化

## 核心功能

1. **IP地址管理**：
   - 4种状态：可用、已分配、保留、冲突
   - 并发分配保护（数据库行锁 + CAS原子更新）
   - 自助分配向导（选择子网 → 可视化网格选IP → 填写设备信息）
   - 批量操作

2. **子网管理**：
   - CIDR格式（192.168.10.0/24）
   - 自动初始化IP池
   - 使用率统计

3. **SNMP网络扫描**：
   - 异步扫描ARP表（每10分钟）
   - 支持SNMPv2c/v3
   - 自动冲突检测（MAC地址变化）

4. **审计日志**：
   - 记录所有IP操作
   - 不可修改

5. **仪表板**：
   - 统计卡片、图表
   - 高负载子网监控
   - 最近操作日志

## 关键技术难点

1. **离线Tailwind CSS部署**：
   - 原型HTML使用 `<script src="https://cdn.tailwindcss.com">`
   - 需要本地编译为静态CSS文件
   - 提取自定义颜色配置（#2463eb主色、#111621暗黑背景等）

2. **并发IP分配**：
   - 使用 `select_for_update()` 行锁
   - CAS模式验证原子更新
   - 事务隔离

3. **IP可视化网格**：
   - 256个IP的交互式网格（/24子网）
   - CSS Grid + Alpine.js
   - 颜色编码状态

4. **浏览器缩放适配**：
   - 支持80%-125%缩放比
   - 响应式设计优化
